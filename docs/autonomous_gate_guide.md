# フック駆動型自律検証＆セキュリティガードレール導入ガイド (Autonomous Worktree Flow)

このプロジェクトには、エージェント用規約（`AGENTS.md` / `project-config.json`）と連携し、隔離ワークツリーでの開発を自律的に検証・保護するライフサイクルフック環境が導入されています。
本ガイドでは、対応する CLI ツール（Codex CLI、Antigravity CLI、Claude Code）でのセットアップ方法、動作仕様、トラブルシューティングについて解説します。

---

## 🚀 はじめに (初期セットアップ)

新しい Git ワークツリーを作成した際、または新セッションを開始した際、以下のセットアップスクリプトを実行することで、フック環境が自動構成されます。

```bash
# ワークツリー初期化スクリプトの実行
./scripts/setup-worktree-env.sh
```

このスクリプトを実行すると、自動的に以下の処理が行われます：
1. `scripts/autonomous-gate.sh` に実行権限を付与。
2. Codex / Antigravity 向けの設定ファイル `hooks.json` および `.codex/hooks.json` を生成/既存ファイルとマージ。
3. Claude Code 向けの設定ファイル `.claude/settings.json` を生成/既存ファイルとマージ。
4. セキュリティガードレールスクリプト（シークレット漏洩防止、破壊的gitコマンドのブロック）を `.claude/hooks/` に配備。

---

## 🛠 各スクリプトの役割と動作仕様

### 1. `scripts/setup-worktree-env.sh` (環境初期化)
* **概要**: ワークツリー内でエージェントが動き出す前に必要なライフサイクルフックとセキュリティポリシーを自動配備します。
* **配備されるフック定義**:
  * **`Stop`**: エージェントがターン（セッション）を終了しようとした際に品質ゲート（`autonomous-gate.sh`）を走らせる。
  * **`PreToolUse`**: ファイル編集時やコマンド実行時にセキュリティ漏洩や破壊的操作を検知してブロックする。

### 2. `scripts/autonomous-gate.sh` (自律検証ゲート)
* **概要**: エージェントが「実装完了」としてセッションを終了しようとした (`Stop` イベント) 瞬間に自動実行され、プログラムが品質基準を満たしているかを強制検証します。
* **動作フロー**:
  1. `project-config.json` 内の `"commands"` キーをパースします。
  2. 定義されている検証コマンド (`lint` / `typecheck` / `test` / `check_architecture` / `quality_check`) を順次実行します。
  3. **[検証失敗時]**:
     * 失敗したエラーログとコマンド名をキャプチャします。
     * 各 CLI ツールが解釈できる差し戻し用 JSON（`{"decision": "block", "reason": "..."}`）を標準出力に返却します。
     * これにより、エージェントは強制的にセッションが継続され、提示されたエラーログを元に自律的（自動的）に修正コードを書くループに入ります。
  4. **[検証成功時]**:
     * `{ "continue": true }` または空の JSON（`{}`）を出力し、正常にセッション終了（Victory）を認めます。

## 🔒 セキュリティガードレール (PreToolUse)

* **シークレット漏洩ガード (`secret-leak-guard.sh`)**:
  `write_to_file` やファイル置換ツールで書き込まれる内容に、Google Cloud APIキー (`AIzaSy...`) や Slackトークン (`xoxb...`)、RSA秘密鍵などのシークレットが含まれている場合、ツール実行前に即座に遮断 (`decision: deny`) します。
* **破壊的 Git 操作ガード (`destructive-git-guard.sh`)**:
  `git push --force` や `git reset --hard`、`git clean -fd` などの破壊的 git 操作コマンドが実行されようとした場合、実行前に即座に遮断します。

## 🔍 動作の確認・検証方法

### 自律ゲートのテスト方法 (エラー差し戻しの確認)
自律ゲートが正しくエージェントを差し戻せるか検証する手順です。

1. **テストを意図的に落とす**:
   型チェックやユニットテストが落ちるようなバグをコード（例: `src/` 配下）に意図的に埋め込みます。
2. **検証ゲートの手動実行**:
   ```bash
   # 手動でフックを実行し、エラー検知と JSON 出力を確認する
   ./scripts/autonomous-gate.sh
   ```
   * **期待される出力**: 失敗したコマンドのログが含まれた `{ "continue": false, "decision": "continue", "reason": "..." }` の形式の JSON が標準出力に表示されること。

3. **フックのテスト**:
   エージェント上で `Stop` をシミュレートするか、実際にテストが落ちた状態でエージェントに「作業完了」と指示した際、自動で実行が再開され、エラー修正を試み始めることを確認します。
