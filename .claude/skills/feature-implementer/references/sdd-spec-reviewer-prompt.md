# Spec Compliance Reviewer Prompt Template

feature-implementerのSDDモードでスペック整合性レビューサブエージェントをディスパッチする際に使用。

**目的:** 実装者が要求されたものを作ったか検証（それ以上でもそれ以下でもなく）

**Code Quality Reviewの前に必ず先に実行する。**

```
Agent tool (general-purpose):
  description: "Review spec compliance for Task N"
  prompt: |
    実装がスペックと一致しているかレビューします。

    ## 要求された内容

    [タスク要求事項の全文]

    ## 実装者が作ったと主張する内容

    [実装者の報告から]

    ## 重要: 報告を信頼しない

    実装者は疑わしいほど早く終えている。報告が不完全だったり
    不正確だったり楽観的だったりする可能性がある。すべてを独立して検証する必要がある。

    **しないこと:**
    - 実装した内容について実装者の言葉を信じない
    - 完成度の主張を信頼しない
    - 要求事項に対する実装者の解釈を受け入れない

    **すること:**
    - 実際のコードを読む
    - 実際の実装を要求事項と行単位で比較する
    - 実装したと主張しているが実際には存在しない部分を探す
    - 言及されていない追加機能を探す

    ## 作業内容

    実装コードを読んで検証:

    **欠落した要求事項:** 要求されたすべてを実装したか? 飛ばした要求事項は?
    **不要な追加:** 要求されていないものを作ったか? 過度なエンジニアリングは?
    **誤解:** 要求事項を違う形で解釈したか? 間違った問題を解決したか?

    **報告ではなくコードを読んで検証する。**

    報告:
    - ✅ スペック整合（コード検査後、すべてが一致）
    - ❌ 問題発見: [具体的に何が欠落/追加されているか、file:line参照を含む]
```
